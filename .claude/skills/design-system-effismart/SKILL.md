# EffiSmart — Clair & Verre (light and dark operations console)

## Mission
Give energy auditors a calm, technical operations console in two modes chosen by each user with a
top-bar button: **Clair** (default) — white frame, very rounded soft-grey cards, slate sidebar, inspired by a
smart-home dashboard — and **Verre** (dark) — slate night canvas with soft colored halos and frosted-glass
panels. Same EffiSmart colors in both: one green action color, slate ink, sky for gas, monospaced figures.
Data is J+1: never promise "real time" (the photo badge reads « Données J+1, au … », never « Live »).

## Brand
- Product/brand: EffiSmart
- Audience: energy auditors (primary), SME/ETI clients in read-only mode (secondary)
- Product surface: web app dashboard (Streamlit local version, React version)
- Origin: dark mode generated by UI/UX Pro Max for "energy monitoring SaaS dashboard B2B auditors compliance
  analytics dark" (glassmorphism, dark tech + status green, Fira Code / Fira Sans); light mode and dashboard
  layout adapted from a smart-home dashboard reference supplied by the product owner (October 2026),
  keeping EffiSmart colors; all pairs contrast-checked.
- Alternate dark theme: "Nova Dark" (violet) kept behind `EFFISMART_THEME=nova`.
- Mode: per user (`users.ui_theme` « clair » / « sombre »), restored at login; `ui_theme.set_mode` at the start
  of each Streamlit run, then chart colors (`ui.PRIMARY`, `ui.MUTED`…) follow the session's mode.

## Style Foundations
- Light (Clair): canvas #e7ecf2 with faint green/sky halos; white main frame (radius 32px, soft shadow);
  cards `color-surface` #f1f5f9 with soft shadow `0 1px 2px / 0 12px 32px -16px` slate; inner chips and rows
  white; slate sidebar #0f172a with light text. Soft shadows allowed in light mode only.
- Dark (Verre): translucent panels (`backdrop-filter: blur(16px) saturate(140%)`), hairline light borders,
  three soft radial halos (green, sky, indigo), no shadows.
- Typography:
  - `font-sans`: Fira Sans 400/500/600/700 — body, labels, buttons.
  - `font-mono`: Fira Code 600/700 — KPI values only (read like a meter display). Titles stay in Fira Sans.
  - Scale: `text-label` 14px/600 sentence case · `text-sm` 14px · `text-base` 16px ·
    `text-lg` 20px/700 · `text-title` 34px/700 · `text-display` 36–40px/700 (tabular figures).
- Color tokens — light (text pairs ≥ 4.5:1, UI boundaries and chart series ≥ 3:1 on white):
  - `color-surface` #f1f5f9 · `color-surface-2` #ffffff · `color-surface-3` #e2e8f0 · `color-border` #e2e8f0
  - `color-border-strong` #64748b (inputs, 4.8:1) · `color-text` #0f172a · `color-text-2` #1e293b · `color-muted` #475569 (7.6:1)
  - `color-primary` #22c55e with `color-on-primary` #0f172a (7.8:1); chart main series #16a34a (3.3:1), gas #0284c7 (4.1:1)
  - `color-ink` #0f172a / `color-on-ink` #f8fafc (highlighted card, selected row, « Ajouter un site »)
  - `color-icon` #22c55e on `color-icon-bg` #0f172a (dark round icon badges)
  - badges: success #166534 on #dcfce7 · danger #9f1239 on #ffe4e6 · warning #92400e on #fef3c7
  - `color-focus` #0f172a (2px ring)
- Color tokens — dark (Verre):
  - `color-bg` #0f172a · `color-surface` rgba(30,41,59,0.62) (≈ #1b2538 over bg)
  - `color-surface-2` rgba(39,51,73,0.85) (inputs, active states) · `color-surface-3` #273349
  - `color-border` rgba(148,163,184,0.18) (decorative) · `color-border-strong` #94a3b8 (inputs, 4.95:1)
  - `color-text` #f8fafc (14.67:1 on surface) · `color-text-2` #e2e8f0 · `color-muted` #94a3b8 (5.99:1)
  - `color-primary` #22c55e (main series 6.74:1) · `color-on-primary` #0f172a (7.83:1 on green)
  - `color-series-2` #38bdf8 (gas / comparison, 7.16:1)
  - `color-ink` #f8fafc / `color-on-ink` #0f172a (the highlighted card inverts: white on the night canvas)
  - `color-success` #86efac on #0e3018 · `color-danger` #fda4c8 on #290521 · pills #bbf7d0 on green tint (10.01:1)
  - `color-focus` #ffffff (2px ring)
- Spacing scale (4-pt grid): 4, 8, 12, 16, 24, 32, 48. Card padding 24–28; gap 16–24.
- Radius: `radius-pill` 999px (buttons, badges, inputs, selects, chips) · `radius-card` 28px light, 26px dark ·
  site rows 22px · main frame 32px (light).
- Motion: 150ms ease-out on color changes; blur removed under prefers-reduced-motion.

## Components
- **Top bar**: client pill, search, period (green outlined pill), alerts (count + dot), mode toggle
  (moon / sun, accessible name « Passer en mode sombre / clair »), help, primary « Données RSE », account
  avatar (ink circle). Every control is functional. Wraps on several lines under 640px, never overlaps.
- **Sidebar**: logo (light version on the slate sidebar), « Menu » label, one Material icon before each page,
  active item green tint.
- **Page header**: client name (only when it identifies the context) → title → subtitle.
- **Dashboard head** (`site_overview`):
  - Site photo card (uploaded by the auditor, PNG/JPEG ≤ 10 MB; fallback: load-curve carpet artwork),
    top-left freshness chip with green dot « Données J+1, au … », top-right white measurement chips (icon +
    value; label read by screen readers and shown on hover): consumption, cost, emissions, kWh/m² for the
    period; site name and address on a bottom scrim.
  - Sites card: rounded rows (round avatar, name, « N point(s), X MWh », chevron button « Afficher … »);
    the shown site is an ink row; « Ajouter un site » ink pill for auditors only.
- **Dashboard cards** (`ui.panels`, CSS grid with container queries: three columns 1.3 / 1 / 1, two columns
  with the first card full width under 900px of content, one column under 560px; equal heights): Consommation
  (value, trend pill, sparkline, stat pills: round dark icon + value + label); Coût estimé (ink card, sparkline,
  white emissions sub-card: value and trend on one line that wraps instead of overflowing); Répartition
  (two-color ring, electricity green / gas sky, values written below). Card values scale with the card width
  (`clamp(26px, 13cqi, 40px)`). The sites list moves under the photo when both no longer fit side by side.
- **KPI grid** (other pages): one hero card and compact cards (icon + label, value, trend pill, sparkline).
  Energy, cost and emissions: increase = danger, decrease = success.
- **Buttons**: primary = green pill with dark text; secondary = pill with `color-border-strong` outline
  (white fill in light mode).
- **Charts**: transparent background, green main series with gradient area fading to transparent green, sky
  for gas, faint grid, muted labels; always a text summary and a « Voir les données » table.
- **Streamlit natives in light mode**: Streamlit stays configured dark; selects (react-aria `role=group`),
  menus (`*VirtualDropdown`), popovers, date fields, radios, checkboxes, tabs, expanders and alerts are
  repainted by CSS; data grids (canvas) are inverted (`filter: invert(1) hue-rotate(180deg)`).
- **Artwork** (canvas-design): calm carpet-plot panels in the same palette for the login screen, empty states
  and the photo fallback; decorative images carry a descriptive `alt`.

## Accessibility
- Target: WCAG 2.2 AA
- Keyboard-first interactions required; focus-visible ring 2px `color-focus`, 2px offset.
- Sticky top bar must never hide focus (`scroll-padding-top`).
- Icon-only controls expose a text name; color is never the only carrier (arrows, text, labels).
- Target size ≥ 44×44 px for top-bar controls and site-row chevrons, ≥ 24×24 px elsewhere.

## Writing Tone
concise, confident, implementation-focused — French UI copy, sentence case, no "temps réel", no « Live ».

## Rules: Do
- Use semantic tokens (CSS custom properties), not raw hex values in components; chart colors through
  `ui.palette()` / `ui.PRIMARY` so they follow the mode.
- Define all required states: default, hover, focus-visible, active, disabled, loading, error.
- Escape all dynamic text rendered as HTML.
- Keep KPI grids responsive (auto-fit, min 240px) so values are never truncated.
- Draw proportions at their true size (rings, bars): no minimum width that misstates a value.

## Rules: Don't
- Do not allow low-contrast text or hidden focus indicators.
- Do not stack glass on glass more than two levels deep (readability).
- Do not add decorative controls that do nothing (the reference's device toggles have no EffiSmart equivalent:
  the platform advises, it never switches equipment).
- Do not use a second action color; no drop shadows in dark mode.
- Do not use generic template tells (frontend-design skill): tracked ALL-CAPS labels, middle-dot meta
  strings, '→' in text, 'WORD — fragment' labels, identical cards with no hierarchy.

## QA Checklist
- [ ] All text pairs ≥ 4.5:1, UI boundaries and series ≥ 3:1, in both modes.
- [ ] Every trend/status readable without color.
- [ ] No truncated or overflowing value at 1440, 1280, 1100, 960, 800, 640 and 390px, in both modes (scripted check:
  no element's box outside its card); top bar without overlap at 390px.
- [ ] Focus ring visible on buttons, inputs, nav items; never hidden by the top bar.
- [ ] Client (read-only) screens show no write controls (no « Ajouter un site », no photo upload).
- [ ] Mode toggle restores the user's choice at the next login.
