# EffiSmart — Verre (Glass Operations)

## Mission
Give energy auditors a calm, technical operations console: slate night canvas with soft colored
halos, frosted-glass panels, one green action color and monospaced figures for precise reading.
Data is J+1: never promise "real time".

## Brand
- Product/brand: EffiSmart
- Audience: energy auditors (primary), SME/ETI clients in read-only mode (secondary)
- Product surface: web app dashboard (Streamlit local version, React version)
- Origin: design system generated by UI/UX Pro Max for "energy monitoring SaaS dashboard B2B
  auditors compliance analytics dark" (pattern: operations; style: glassmorphism; palette:
  dark tech + status green; typography: Fira Code / Fira Sans), then contrast-checked and adapted.
- Alternate theme: "Nova Dark" (violet) kept behind `EFFISMART_THEME=nova`.

## Style Foundations
- Visual style: dark glassmorphism — translucent panels (`backdrop-filter: blur(16px) saturate(140%)`),
  hairline light borders, three soft radial halos (green, sky, indigo) on the canvas, no shadows.
- Typography:
  - `font-sans`: Fira Sans 400/500/600/700 — body, labels, buttons.
  - `font-mono`: Fira Code 600/700 — KPI values only (read like a meter display). Titles stay in Fira Sans.
  - Scale: `text-label` 14px/600 sentence case · `text-sm` 14px · `text-base` 16px ·
    `text-lg` 20px/700 · `text-title` 34px/700 · `text-display` 36px/700 (tabular figures).
- Color tokens (text pairs ≥ 4.5:1, UI boundaries and chart series ≥ 3:1, all computed):
  - `color-bg` #0f172a · `color-surface` rgba(30,41,59,0.62) (≈ #1b2538 over bg)
  - `color-surface-2` rgba(39,51,73,0.85) (inputs, active states) · `color-surface-3` #273349
  - `color-border` rgba(148,163,184,0.18) (decorative) · `color-border-strong` #94a3b8 (inputs, 4.95:1)
  - `color-text` #f8fafc (14.67:1 on surface) · `color-text-2` #e2e8f0 · `color-muted` #94a3b8 (5.99:1)
  - `color-primary` #22c55e (main series 6.74:1) · `color-on-primary` #0f172a (7.83:1 on green)
  - `color-series-2` #38bdf8 (gas / comparison, 7.16:1)
  - `color-success` #86efac on #0e3018 · `color-danger` #fda4c8 on #290521 · pills #bbf7d0 on green tint (10.01:1)
  - `color-focus` #ffffff (2px ring)
- Spacing scale (4-pt grid): 4, 8, 12, 16, 24, 32, 48. Card padding 28; gap 24.
- Radius: `radius-pill` 999px (buttons, badges, inputs) · `radius-card` 18px.
- Motion: 150ms ease-out on color changes; blur removed under prefers-reduced-motion.

## Components
- **Top bar**: glass strip — client pill, search, period (outlined pill), alerts (count + dot),
  help, primary "+ Nouvel export", account avatar. Every control is functional.
- **Sidebar**: glass, logo mark (green→sky gradient circle), "MENU" label, active item green tint.
- **Page header**: client name (only when it identifies the context) → title → subtitle.
- **KPI grid**: one hero card (total consumption, 2 × 2 cells, 64px value, tall sparkline) and four
  compact cards (icon + label, value, trend pill, sparkline). The comparison note appears once, on the hero.
  Energy, cost and emissions: increase = danger, decrease = success.
- **Buttons**: primary = green pill with dark text; secondary = transparent pill, `color-border-strong` outline.
- **Charts**: transparent background, green main series with gradient area, sky for gas,
  faint grid, muted labels; always a text summary and a "Voir les données" table.
- **Artwork** (canvas-design): calm carpet-plot panels in the same palette for the login screen
  and empty states; decorative images carry a descriptive `alt`.

## Accessibility
- Target: WCAG 2.2 AA
- Keyboard-first interactions required; focus-visible ring 2px `color-focus`, 2px offset.
- Sticky top bar must never hide focus (`scroll-padding-top`).
- Icon-only controls expose a text name; color is never the only carrier (arrows, text, labels).
- Target size ≥ 44×44 px for top-bar controls, ≥ 24×24 px elsewhere.

## Writing Tone
concise, confident, implementation-focused — French UI copy, sentence case, no "temps réel".

## Rules: Do
- Use semantic tokens (CSS custom properties), not raw hex values in components.
- Define all required states: default, hover, focus-visible, active, disabled, loading, error.
- Escape all dynamic text rendered as HTML.
- Keep KPI grids responsive (auto-fit, min 240px) so values are never truncated.

## Rules: Don't
- Do not allow low-contrast text or hidden focus indicators.
- Do not stack glass on glass more than two levels deep (readability).
- Do not add decorative controls that do nothing.
- Do not use drop shadows or a second action color.
- Do not use generic template tells (frontend-design skill): tracked ALL-CAPS labels, middle-dot meta
  strings, '→' in text, 'WORD — fragment' labels, identical cards with no hierarchy.

## QA Checklist
- [ ] All text pairs ≥ 4.5:1, UI boundaries and series ≥ 3:1.
- [ ] Every trend/status readable without color.
- [ ] No truncated KPI values at 1280px and 800px widths.
- [ ] Focus ring visible on buttons, inputs, nav items; never hidden by the top bar.
- [ ] Client (read-only) screens show no write controls.
